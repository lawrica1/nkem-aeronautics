# Deploying Nkem Aeronautics on Render

`render.yaml` in the repository root describes two Render web services:

| Service | Folder | What it runs |
|---|---|---|
| `nkem-api` | `server/` | Express API (`npm start`), health check at `/health` |
| `nkem-web` | `client/` | Next.js website (`npm run build`, then `npm start`) |

The database stays on **Neon**. Nothing in Render stores data.

## 1. Create the services

1. Sign in at [dashboard.render.com](https://dashboard.render.com) and connect your GitHub account if asked.
2. Click **New → Blueprint**, pick the `Narcisse1/NkemWeb` repository, and choose the branch to deploy
   (`main` for the live site, or `claude/funny-bell-fph5vm` to preview the redesign).
3. Render lists both services and asks for every setting marked *sync: false*. Fill them in as below,
   then click **Apply**.

## 2. Settings to enter

### `nkem-api`

| Setting | What to put |
|---|---|
| `DATABASE_URL` | Your Neon connection string (Neon → Connection details). Keep `?sslmode=require&connect_timeout=15` on the end. |
| `CLIENT_ORIGIN` | The main website address, no trailing slash. First deploy: `https://nkem-web.onrender.com` (use the address Render shows for `nkem-web`). After the domain is moved: `https://nkemaeronautics.com`. |
| `CORS_ORIGINS` | Any other addresses of the website, comma-separated, e.g. `https://www.nkemaeronautics.com,https://nkem-web.onrender.com`. Can be left empty. |
| `TERMII_API_KEY`, `TERMII_SENDER_ID` | From your Termii account. Without the key, sign-up codes are only written to the server log. |
| `BREVO_API_KEY` *or* `SMTP_PASS` | Email delivery. Brevo is preferred in production; `SMTP_PASS` is a Gmail App Password. |
| `R2_ENDPOINT`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_PUBLIC_BASE_URL` | Cloudflare R2, for photo and video uploads. |
| `FLUTTERWAVE_SECRET_KEY`, `FLUTTERWAVE_WEBHOOK_HASH` | Online payments. Use sandbox keys until Flutterwave approves the account. |
| `ADMIN_EMAIL`, `ADMIN_PHONE` | Where new-enquiry alerts go. Optional. |
| `ADMIN_SIGNUP_CODE` | Leave empty to keep public admin sign-up switched off. |
| `ANTHROPIC_API_KEY` *or* `GEMINI_API_KEY` | For the "Ask Nkem" website assistant. Claude: console.anthropic.com → API Keys (paid per use). Gemini: aistudio.google.com → Get API key (free tier; Google may use free-tier chats to improve its products). Claude is used if both are set. With neither, the chat button shows contact details instead of answering. |

`JWT_SECRET` is generated by Render automatically. Everyone will need to log in again once after the move.

### `nkem-web`

| Setting | What to put |
|---|---|
| `NEXT_PUBLIC_API_URL` | The API address plus `/api`, e.g. `https://nkem-api.onrender.com/api`. |

`NEXT_PUBLIC_API_URL` is built into the website, so after changing it use **Manual Deploy → Clear build cache & deploy** on `nkem-web`.

## 3. Check it works

1. Open `https://nkem-api.onrender.com/health`. It should answer with a short JSON status.
2. Open the `nkem-web` address, sign up, and confirm you receive the code by SMS.
3. Create the first admin from the `nkem-api` **Shell** tab:
   `npm run create-admin -- admin@example.com "a-strong-password" "Admin"`

## 4. Move nkemaeronautics.com

1. In `nkem-web` → **Settings → Custom Domains**, add `nkemaeronautics.com` and `www.nkemaeronautics.com`.
2. Create the DNS records Render shows at your domain registrar.
3. Update `CLIENT_ORIGIN` to `https://nkemaeronautics.com` and add the `www` and `onrender.com` addresses to `CORS_ORIGINS`.
4. Optional: add `api.nkemaeronautics.com` to `nkem-api`, then set `NEXT_PUBLIC_API_URL` to `https://api.nkemaeronautics.com/api` and redeploy `nkem-web`.
5. In Flutterwave → Webhooks, point the webhook at `https://<api address>/api/payments/webhook`.

## Plans

The Blueprint uses the **Starter** plan for both services so they never sleep. The **Free** plan works
for testing, but each service sleeps after 15 idle minutes and the next visitor waits about a minute.
Change `plan:` in `render.yaml`, or in each service's settings.
